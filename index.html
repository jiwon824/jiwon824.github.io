Spring Boot 기반 서비스에서 API와 데이터 모델을 설계하고, 테스트와 운영 환경까지 연결해 문제를 해결해 왔습니다. 클라이언트 입력에 의존하던 채점을 서버 중심 구조로 전환하고, 테스트 종료 지연의 원인을 컨테이너와 자원 생명주기에서 찾아 전체 테스트 시간을 약 77% 단축했습니다. 이 문제도 ‘개별 테스트 656ms, 전체 6분’이라는 측정 기록의 모순에서 출발했습니다. 문제의 증상, 시도한 명령, 확인 결과를 트러블슈팅 노트와 블로그로 남기고, 다음 문제는 그 기록에서 시작합니다.

철학과에서 컴퓨터공학을 복수전공하며 개발을 시작했습니다. 로컬에서 만든 서비스를 EC2에 배포해 다른 사람이 접근할 수 있게 되었을 때 느낀 성취감이 지금까지의 방향을 지지해 왔고, SSAFY에서 인프라 역할을 두 차례 맡은 뒤 백엔드 개발자에게도 인프라 역량이 중요하다고 판단했습니다. 현재는 서버와 운영 환경까지 책임지는 백엔드 개발자를 지향합니다.
